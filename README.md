# Supermarket Demand Prediction System

A Python-based inventory forecasting and demand prediction system for supermarkets.

## Features
- Demand forecasting
- Regional sales analysis
- Risk product detection
- Dashboard generation
- Historical trend analysis
- Stock recommendations

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
